# 测试策略

## DDD应用的测试分层

在DDD应用中，测试策略应该按照架构层次进行分层，每层有对应的测试方法和工具。

### 测试金字塔

```
         E2E Tests (少量)
        /             \
       /               \
      /                 \
     /    Integration    \  (中等数量)
    /       Tests         \
   /                       \
  /                         \
 /   Unit Tests (大量)      \
/___________________________\
```

**测试层次：**
1. **单元测试**：测试单个类或方法
2. **集成测试**：测试多个组件的协作
3. **端到端测试**：测试完整的业务流程

```java
@SpringBootTest
@Transactional
class LoanRepositoryIntegrationTest {

    @Autowired
    private LoanRepository loanRepository;

    @Autowired
    private CopyRepository copyRepository;

    @Test
    void shouldSaveAndFindLoan() {
        // Given
        Copy copy = new Copy(new BookId(), new BarCode("123456"));
        copyRepository.save(copy);

        Loan loan = new Loan(copy.getId(), new UserId(), loanRepository);

        // When
        loanRepository.save(loan);
        Optional<Loan> found = loanRepository.findById(loan.getLoanId());

        // Then
        assertTrue(found.isPresent());
        assertEquals(copy.getId(), found.get().getCopyId());
    }

    @Test
    void shouldCheckAvailability() {
        // Given
        Copy copy = new Copy(new BookId(), new BarCode("123456"));
        copyRepository.save(copy);

        // When - 没有借阅记录时
        boolean availableBefore = loanRepository.isAvailable(copy.getId());
        assertTrue(availableBefore);

        // 创建借阅记录
        Loan loan = new Loan(copy.getId(), new UserId(), loanRepository);
        loanRepository.save(loan);

        // When - 有未归还的借阅记录时
        boolean availableDuring = loanRepository.isAvailable(copy.getId());
        assertFalse(availableDuring);

        // 归还图书
        loan.returned();
        loanRepository.save(loan);

        // When - 借阅记录已归还时
        boolean availableAfter = loanRepository.isAvailable(copy.getId());
        assertTrue(availableAfter);
    }
}
```

### 完整用例集成测试

```java
@SpringBootTest
@Transactional
class BookLendingIntegrationTest {

    @Autowired
    private AddBookToCatalogUseCase addBookToCatalogUseCase;

    @Autowired
    private RegisterBookCopyUseCase registerBookCopyUseCase;

    @Autowired
    private RentBookUseCase rentBookUseCase;

    @Autowired
    private ReturnBookUseCase returnBookUseCase;

    @Autowired
    private BookRepository bookRepository;

    @Autowired
    private CopyRepository copyRepository;

    @Autowired
    private LoanRepository loanRepository;

    @Test
    void shouldCompleteFullBookLendingCycle() {
        // 1. 添加书籍到目录
        Isbn isbn = new Isbn("978-3-16-148410-0");
        addBookToCatalogUseCase.execute(isbn);

        List<Book> books = (List<Book>) bookRepository.findAll();
        assertEquals(1, books.size());
        BookId bookId = books.get(0).getId();

        // 2. 注册副本
        BarCode barCode = new BarCode("123456");
        registerBookCopyUseCase.execute(bookId, barCode);

        List<Copy> copies = (List<Copy>) copyRepository.findAll();
        assertEquals(1, copies.size());
        CopyId copyId = copies.get(0).getId();
        assertTrue(copies.get(0).isAvailable());

        // 3. 借书
        UserId userId = new UserId();
        rentBookUseCase.execute(copyId, userId);

        List<Loan> loans = (List<Loan>) loanRepository.findAll();
        assertEquals(1, loans.size());
        LoanId loanId = loans.get(0).getLoanId();

        Copy borrowedCopy = copyRepository.findById(copyId).orElseThrow();
        assertFalse(borrowedCopy.isAvailable());

        // 4. 还书
        returnBookUseCase.execute(loanId);

        Loan returnedLoan = loanRepository.findById(loanId).orElseThrow();
        assertNotNull(returnedLoan.getReturnedAt());

        Copy availableCopy = copyRepository.findById(copyId).orElseThrow();
        assertTrue(availableCopy.isAvailable());
    }
}
```

```java
@SpringBootTest
class LibraryApplicationTests {

    @Test
    void verifyModules() {
        ApplicationModules modules = ApplicationModules.of(LibraryApplication.class);

        // 验证模块结构
        modules.verify();

        // 打印模块文档
        System.out.println(modules.toString());
    }

    @Test
    void verifyNoCyclicDependencies() {
        ApplicationModules modules = ApplicationModules.of(LibraryApplication.class);

        List<String> violations = modules.stream()
            .flatMap(module -> module.getDependencies().stream())
            .filter(dependency -> dependency.getType() == DependencyType.CYCLIC)
            .map(Dependency::getName)
            .toList();

        assertTrue(violations.isEmpty(), "Found cyclic dependencies: " + violations);
    }
}
```

### 覆盖率目标

| 层次 | 目标覆盖率 | 原因 |
|------|-----------|------|
| 领域层 | 90%+ | 核心业务逻辑，需要充分测试 |
| 应用层 | 80%+ | 用例编排，重要但相对简单 |
| 基础设施层 | 70%+ | 技术实现，可以适当降低 |

## 测试策略总结

1. **单元测试**：测试领域对象和业务逻辑
2. **集成测试**：测试组件协作和完整用例
3. **Testcontainers**：使用真实容器进行集成测试
4. **模块验证**：使用Spring Modulith验证架构
5. **测试隔离**：确保测试之间互不影响
6. **命名规范**：使用清晰的测试命名
7. **Given-When-Then**：结构化测试代码
8. **覆盖率目标**：设定合理的覆盖率要求

良好的测试策略是保证DDD应用质量的基础，本项目展示了从单元测试到集成测试的完整测试体系。
